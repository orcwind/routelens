# RouteLens 设计文档（V1.0）

> **项目名称：** RouteLens
> **定位：** Path of Exile 1 / Path of Exile 2 开荒计时与路线管理工具
> **目标用户：** 普通玩家、开荒玩家、练习玩家（非 Speedrun 官方记录）

---

# 一、项目背景

目前 PoE 玩家主要使用 LiveSplit 进行开荒计时。

LiveSplit 非常优秀，但它的设计目标是 **一次完整连续的 Speedrun**。

```
Start
↓

连续游戏

↓

Finish
```

然而，大多数普通玩家并不是这样玩。

例如：

```
总开荒时间：

6~10 小时
```

很多玩家：

```
晚上玩 2 小时

↓

第二天继续

↓

再玩 3 小时

↓

周末完成
```

他们需要的是：

> **练习自己的路线，而不是挑战官方 Speedrun。**

目前 LiveSplit 不支持：

* 保存当前 Run
* 恢复 Run
* 自动记录自己的路线
* 根据游戏语言生成 Split

因此设计 RouteLens。

---

# 二、设计目标

RouteLens 的目标不是替代 LiveSplit。

而是提供：

> **Persistent Campaign Run（持久化开荒 Run）**

让玩家能够：

* 自动记录路线
* 自动计时
* 随时退出
* 随时恢复
* 长期分析自己的开荒效率

---

# 三、核心理念

RouteLens 不是 Speedrun 工具。

它是：

> **Campaign Practice Tool**

所有设计围绕：

**练习**

而不是：

**比赛**

---

↓

```

```

```

## 功能三：Persistent Run（核心功能）

```

↓

Finish
```

```

↓

↓

↓

# 五、Route 系统

Route 不是官方路线。

而是：

> 玩家自己的路线。

例如：

```

Clearfell

Mud Burrow

Red Vale

Ogham Village
```

不同玩家：

完全不同。

RouteLens 不限制。

# 十五、产品定位

RouteLens 不是：

> 一个新的 LiveSplit。

也不是：

> 一个官方 Speedrun 工具。

RouteLens 的定位是：

> **Persistent Campaign Timer**

专门解决 PoE 玩家：

> **一次开荒太长，无法连续完成。**

同时提供：

* 自动路线生成
* 自动 Split
* 自动保存
* 自动恢复
* 长期路线分析

让玩家能够持续优化自己的开荒效率，而无需受 LiveSplit「一次 Run 必须连续完成」这一设计限制。
